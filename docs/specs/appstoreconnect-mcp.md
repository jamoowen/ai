# App Store Connect MCP v1

This is a local STDIO MCP server backed by a reusable Go `appstoreconnect` client. It exposes exactly five tools: `asc_search_operations(query, method?, limit?)`, `asc_describe_operation(operationId)`, `asc_read(invocation)`, `asc_write(invocation)`, and `asc_delete(invocation)`. An invocation contains only `operationId`, path parameters, query values, and an optional JSON object body. Agents cannot choose URLs, HTTP methods, headers, or credentials. Agents should search, describe, and then invoke; they must inspect schemas before mutations and paginate explicitly.

The catalog parses and validates OpenAPI 3 JSON, rejects missing or duplicate operation IDs, searches deterministic lexical metadata, and returns an operation fragment with its effective path and operation parameters plus only its transitively referenced component schemas. It defaults to `api/apple/app-store-connect.openapi.json`. `ASC_OPENAPI_SOURCE` is trusted startup configuration only: it accepts a local path or HTTPS source (20-second timeout, 16 MiB cap). The public raw-GitHub option is `https://raw.githubusercontent.com/jamoowen/ai/refs/heads/main/api/apple/app-store-connect.openapi.json`. HTTP and model-provided sources are forbidden.

Requests resolve solely through the catalog. The base destination is permanently `https://api.appstoreconnect.apple.com/`; redirects that leave that HTTPS host fail. Query and path parameters are schema-derived and validated, with unknown/missing parameters and invalid JSON bodies rejected before transport. Reads permit GET; writes permit POST/PATCH; deletes permit DELETE. Requests use kin-openapi request validation and require its `itc-bearer-token` bearer scheme. Responses are capped by `ASC_MAX_RESPONSE_BYTES` (default 1 MiB), preserve status/content type/safe rate-limit/request ID headers, expose JSON as structured values and text as strings, reject non-empty binary media, and surface bounded non-2xx detail.

Credentials remain in process environment: `ASC_KEY_ID` and `ASC_PRIVATE_KEY_PATH` are required; `ASC_ISSUER_ID` is optional and selects a team token (otherwise an individual token has `sub=user`). The server creates ES256 tokens with `aud=appstoreconnect-v1`, `iat`, `exp`, `kid`, and a five-minute default lifetime (maximum twenty minutes). Tokens/private keys are never returned or logged. `ASC_ALLOW_WRITES=true` and `ASC_ALLOW_DELETES=true` independently enable mutations; otherwise the discoverable tools return policy errors. STDOUT is MCP protocol only; diagnostics use stderr.

Tests cover catalog loading/search/description (including cycles and the checked-in spec), request construction and pre-transport validation, redirect pinning, response representation and limits, independently verified team/individual JWT claims, MCP protocol discovery/routing/policies, and local/remote source boundaries. v1 excludes remote/streamable MCP hosting, binary uploads/downloads, automatic pagination, embeddings/semantic search, workflow convenience tools, and live Apple integration tests.
